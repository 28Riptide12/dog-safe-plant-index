## 🚀 Common Tasks

### Find Plants for My Garden
1. Use text search: "Roses", "Lavender", etc.
2. Or use filters:
   - Category: Flowers, Herbs, Vegetables
   - Season: When you want them to bloom
   - Climate: Use postcode to find your zone
3. See also: [AI Garden Planner](PLANTS_GUIDE.md#ai-garden-planner)

### Track Plants I'm Growing
1. Go to "My Plant Library" tab
2. Click "+ Add Plant" button
3. Search for plant name
4. Enter location (e.g., "Front bed")
5. Add notes about health/care
6. System creates watering reminders

### Manage Care Reminders
1. Go to "My Plant Library" → "Care Schedule"
2. View upcoming tasks (watering, pruning, etc.)
3. Click task to mark complete
4. Next occurrence automatically schedules
5. Export schedule as needed

### Find Plants Safe for My Dog
1. All plants in catalogue are verified non-toxic
2. Read: [Dog Safety Guide](DOG_SAFETY.md)
3. Use filters: Safety status → "Non-toxic to dogs"
4. Read individual plant profiles
5. Still supervise dog in garden

### Export My Data
1. **Favorites**: Go to "My Favorites" → "Export CSV"
2. **Library**: Go to "My Plant Library" → "Export CSV"
3. File downloads, open in Excel/Google Sheets
4. Use for backup or import elsewhere

### Change Display Settings
1. **Dark Mode**: Click moon icon (top right)
2. **Plant Settings**: Click gear icon
3. **Filters**: Use checkboxes and dropdowns
4. **Clear Filters**: Click "Clear Filters" button

## ⚡ Tips & Tricks

### Faster Navigation
- Use text search for specific plants
- Combine filters for precise results
- Apply climate zone filter first (narrows results)
- Star favorites for quick access

### Better Plant Care
- Check plant profile before planting
- Read care requirements fully
- Set reminders for different tasks
- Review care schedule weekly
- Export library for backup

### Dog Safety
- Supervise dog in garden
- Teach "leave it" command
- Remove fallen leaves/seeds
- Check emergency vet numbers
- Have ASPCA poison control saved

### Data Management
- Export regularly (backup)
- Keep notes organized
- Use location names consistently
- Review what's working
- Plan seasonal changes
